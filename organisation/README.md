# Organisation

Canonical DCA organisational meaning: shared organisational reality, structure, governance, boundaries, and organisational interfaces.

This area answers questions such as:

- What is true or validated about DCA across functions?
- How is DCA organised and governed?
- Which roles, boundaries, and interfaces exist?
- How should organisation-wide information be interpreted and routed?

It does not contain day-to-day operational records or AI-provider configuration.
