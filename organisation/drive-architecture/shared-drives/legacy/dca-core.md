# DCA Core — Legacy / Migration Only

## Status
This Shared Drive is a legacy container being migrated and retired.

**Do not create new canonical DCA material here.**

## Why
The drive historically mixes strategy, alignment, reports, finance plans, volunteer material, metrics, coaching, and person-centred working areas. Those categories now have clearer canonical homes elsewhere.

## Routing rule
Classify each existing artifact by what it actually is:
- organisation-wide strategy / structure / alignment → DCA Organisation;
- formal Board governance → DCA Board;
- finance material → DCA Finance;
- function-specific operational material → the relevant functional Shared Drive;
- technical/data implementation → DCA Systems & Data;
- obsolete or superseded material → archive in the correct domain.
