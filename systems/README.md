# Systems

Canonical system and data architecture supporting DCA work.

This area describes technical structures such as platforms, data models, integrations, automation, CRM, Airtable, reporting infrastructure, and technical boundaries.

A system artifact is classified here because of what it technically defines, not merely because System & Structure contributed to it.
