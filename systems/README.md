# Systems

Canonical system and data architecture supporting DCA work.

This area describes technical structures such as platforms, data models, integrations, automation, CRM, Airtable, reporting infrastructure, and technical boundaries.

A system artifact is classified here because of what it technically defines, not merely because System & Structure contributed to it.

## Canonical structural rules

- [DCA Shared System — Structural Rules](./shared-system-structural-rules.md) — platform-independent and model-independent rules for representing DCA organisational and operational reality in shared systems. Implementation-specific standards inherit from these rules.

## Development and production

- [Development, Testing and Production Promotion](./development-testing-and-promotion.md) — environment roles, representative tests, evidence handling, acceptance boundaries and controlled adoption into production.
